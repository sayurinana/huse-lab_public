弘毅楼115B电子竞赛实验室守则试行版-v0.0.1

文件创建时间：2024-11-09_19:22:34

最后编辑时间：2024-11-10_21:57:24

  1. 此守则适用对象：2022级以及之后的电子竞赛实验室成员
  2. 注意！
    • 想要放松放纵😴可以直接待寝室没必要进实验室，毕竟是大学生也是成年人了，管不到🫠
    • 守则、打卡、等等都只是形式，不重要，提出这个文档只是稍微规范化一点，做个简单的纸面约定
    • 主要是作为实验室成员，当然人要来，有事来不了很正常，但是一个星期都不见几次人就离谱了
  3. 只要没课、没有班院校级强制活动的时候，都要来实验室
    • 强制活动是指团日活动、班主任开班会这种的，不过班会一般如果是晚上的话，开完了也要来，毕竟班会几乎不会超过二十分钟，有事要去做正常请假就行
  4. 要求在实验室的时间：
    • 上午从10点开始要在实验室（有课的参考第3点优先上课）
    • 饭点没要求，随便，毕竟这个只是个形式不是强制性的，只是好让心里有个度，不至于漫无目的毫无规矩
      • 但是要是11点人不在说吃饭去了13点了也人不在还是吃饭去了那就离谱了哈🤔
    • 晚上要求在晚自习开始时要在，直到晚上10点半，开始时间同当季晚自习时间一致，例如10月1日至次年4月30日属于春冬季时间晚自习就是19点10分开始
  5. 关于实验室内部请假
    • 主要是两种，长期和短期；内部请假不用请假条，咱没那么大体量，
    • 长期：
      • 情况例如：考研在图书馆备考、临赛时和其他实验室的混合组队在其他实验室训练
      • 或者其他合理原因，@我（通信2301袁观杰）讲一下我记录上
      • 长期请假的成员及其事由我会依次条列在一个文档里（我存在WPS团队文档里，这个是公开的，只是QQ群文件里没有，因为容易被修改，旧的就过期了），
    • 短期：
      • 例如：去寄或者取个快递、生病了不舒服去找老师签字然后回去休息
      • 临时有事就群里冒个泡发消息说声就行
