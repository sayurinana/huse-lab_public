要求​

自行学会使用一个网络代理工具软件，

  • GitHub · Build and ship software on a single, collaborative platform · GitHub（ennnnn，这个玩意儿你挂不挂代理都能访问，只不过不挂代理不稳定，，而已，，，）

要明白，不想用和不能用，完全是两个概念，
